# คู่มือเพิ่มไอเทมน้องหมา

หน้า `/items` เป็นลิสต์ของที่**ครูแนะนำ** ไม่ใช่แคตตาล็อกรวมทุกยี่ห้อ ใส่เฉพาะของที่ครูใช้เองหรือเคยลองจริง

หน้าหมวดแสดงแค่รูปกับชื่อ กดแล้วเข้าหน้าของไอเทมนั้น (`/items/<category>/<slug>`) ซึ่งมีรีวิวเต็มของครู

## กติกา

- `name` ระบุรุ่นให้ชัด เช่น "Front Range Harness" ไม่ใช่แค่ "ฮาเนส"
- `reason` คือรีวิวเต็มของครู ต้องมาจากประสบการณ์ของครูเท่านั้น ห้ามแต่งเพิ่ม ถ้ายังไม่มี ให้เว้นว่างไว้และเก็บเป็นฉบับร่าง
  - ควรตอบ: ใช้กับใคร · ดีตรงไหน · เคยลองอะไรมาก่อน · ข้อเสียหรือไม่เหมาะกับใคร
  - เว้นบรรทัดว่าง (`\n\n`) ระหว่างย่อหน้า
  - ย่อหน้าที่ขึ้นต้นด้วย `ข้อควรรู้:` จะแสดงเป็นกล่องเตือนสีเหลือง
- `slug` คือลิงก์ของหน้า ใช้ a-z 0-9 และขีด - เว้นว่างได้ ระบบจะสร้างจากแบรนด์และชื่อให้
- `priceNote` ไม่ต้องใส่ราคาเป็นตัวเลข เพราะราคาเปลี่ยนบ่อย เว้นว่างได้ หรือบอกระดับราคา เช่น "ราคาสูงกว่าทั่วไป แต่คุ้ม"
- `recommendedBy` ค่าเริ่มต้นคือ "ครูวุฒิ"
- `buyUrl` ใช้ลิงก์ affiliate ที่สร้างจาก Shopee Affiliate (https://) หน้าไอเทมที่มีลิงก์ซื้อจะมีบรรทัดเปิดเผยว่าเป็นลิงก์ affiliate ให้อัตโนมัติ
- รูปควรถ่ายเองหรือใช้รูปที่แบรนด์อนุญาต ไม่ดึงรูปจากหน้าร้านของผู้ขาย
- เรื่องสุขภาพ (โพรไบโอติก อาหารเสริม) ไม่เขียนสรรพคุณรักษาโรค และไม่ใส่ขนาดยา
- ใส่ `"published": false` เสมอ แล้วค่อยเปิดหลังตรวจในหลังบ้าน

## หมวด (`category`) และประเภท (`subcategory`)

| category   | ชื่อ       | subcategory                                                                                                        |
| ---------- | ---------- | ------------------------------------------------------------------------------------------------------------------ |
| `food`     | ของกิน     | `kibble` เม็ด · `wet` เปียก · `barf` บาร์ฟ · `cooked` ปรุงสุก · `chews` ขนมแทะ · `treats` ขนมฝึก · `health` สุขภาพ |
| `gear`     | ของใช้     | `crate` กรง · `pen` คอก · `floor` พื้น · `leash` สายจูง · `harness` ฮาเนส                                          |
| `toys`     | ของเล่น    |                                                                                                                    |
| `training` | อุปกรณ์ฝึก | `fitness` ฟิตเนส                                                                                                   |

หน้าหมวดแสดงทุกชิ้นเป็นค่าเริ่มต้น และมีชิปให้กรองตามประเภท

ตั้งค่าหมวดใน `src/data/item-categories.ts`

## JSON สำหรับวางในหลังบ้าน (หน้า "ไอเทม" → นำเข้าหลายรายการ)

```json
[
  {
    "slug": "brand-model",
    "name": "ชื่อรุ่น",
    "brand": "แบรนด์",
    "category": "gear",
    "subcategory": "harness",
    "reason": "เหตุผลที่ครูเลือก",
    "recommendedBy": "ครูวุฒิ",
    "priceNote": "",
    "buyUrl": "https://s.shopee.co.th/...",
    "imageUrl": "",
    "sort": 0,
    "published": false
  }
]
```

ถ้ามีรายการไหนไม่ผ่าน (เช่น หมวดผิด) จะยังไม่บันทึกเลยสักรายการ และบอกว่ารายการที่เท่าไรผิด
