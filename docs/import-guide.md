# คู่มือทำไฟล์ JSON สำหรับนำเข้าสถานที่ (SawasdeeDog)

ไฟล์นี้เขียนให้ Claude (หรือ AI อื่น) อ่าน เพื่อหาข้อมูลสถานที่แล้วทำ JSON ให้ตรงรูปแบบของหน้า
**หลังบ้าน → รายการบนเว็บ → นำเข้าข้อมูล** (`/admin/places/import`) ของ sawasdeedog.com

> วิธีใช้: แนบไฟล์นี้ให้ Claude แล้วบอกว่า "อ่านคู่มือนี้ แล้วหา [หมวด] ใน [พื้นที่] มา N ที่ ทำเป็น JSON ตามคู่มือ"

---

## 1. ภาพรวมการทำงาน

1. หาข้อมูลจากแหล่งที่ตรวจสอบได้ เช่น เพจทางการ, Google Maps, Wongnai, Lemon8, TikTok, รีวิว
2. ตรวจว่าที่นั้น **ผ่านเกณฑ์ของหมวด** (หัวข้อ 3) ถ้าไม่ผ่าน ไม่ต้องใส่
3. ทำ JSON ตามรูปแบบในหัวข้อ 4–5 แล้วส่งเป็น **code block เดียว** (```json … ```)
4. แอดมินวาง JSON ในหน้านำเข้า ระบบจะเปิดทีละรายการให้ตรวจแก้ก่อนกดบันทึก
5. **รูปภาพไม่ต้องใส่ใน JSON** แอดมินอัปเองในหน้าแก้ไข (ลิงก์รูปจากที่อื่นเสียง่าย และอาจไม่มีสิทธิ์ใช้)

---

## 2. กติกาทั่วไป (สำคัญ)

- **ห้ามเดาข้อมูล** ไม่แน่ใจข้อไหนให้ตัดฟิลด์นั้นทิ้ง แล้วเขียนเหตุผลไว้ใน `notes`
- ทุกรายการต้องมี `sources` อย่างน้อย 1 ลิงก์ (ควรมี 2) ที่ใช้ยืนยันเรื่องหมา
- ข้อมูลขัดกันระหว่างแหล่ง (เบอร์, เวลาเปิด, ที่อยู่) ให้เลือกแหล่งที่ใหม่กว่าหรือเป็นทางการ แล้วบันทึกความต่างไว้ใน `notes`
- หลักฐานยังอ่อน หรือมีเงื่อนไขที่ต้องถามร้านก่อน ให้ใส่ `"published": false` (นำเข้าแบบซ่อนไว้) แล้วอธิบายใน `notes`
- `description` เขียนภาษาไทย 1–2 ประโยค เป็นข้อเท็จจริง ไม่โฆษณา ไม่ใช้คำว่า "แนะนำ", "ดีที่สุด", "ต้องไป"
- ห้ามใส่ข้อมูลส่วนตัวของบุคคล (เบอร์มือถือส่วนตัวของคนรีวิว ฯลฯ) ใส่ได้เฉพาะช่องทางติดต่อของร้าน/บริการ
- ระวังชื่อซ้ำ: ระบบเทียบชื่อและ slug กับของที่มีอยู่แล้ว ถ้าซ้ำจะขึ้นเตือนในหน้านำเข้า

## 3. เกณฑ์คัดเลือกของแต่ละหมวด

| หมวด | เกณฑ์ |
|---|---|
| คาเฟ่ & ร้านอาหาร (`cafe`) | **Dog Friendly ที่จริงใจ** (เข้มที่สุด เพราะหลายร้านติดป้าย Pet Friendly ตามกระแส): ต้อนรับน้องหมาจริง ไม่มีเงื่อนไขแอบแฝง น้องหมาไปได้ทุกที่ที่คนไปได้ **ไม่จำกัดขนาดหรือน้ำหนัก** |
| ที่พัก (`stay`) | ต้องรับน้องหมาหนัก **15 กก. ขึ้นไป** ได้ ส่วนข้อจำกัดอื่น (ห้ามเข้าร้านอาหาร ห้ามลงสระ ฯลฯ) ให้ใส่เป็น `attributes` แบบคำเตือน |
| บริการสัตว์เลี้ยง: โรงพยาบาลสัตว์, ฟิตเนส/กายภาพ, อาบน้ำตัดขน, ฝากเลี้ยง, Pet sitter, ลานวิ่ง & สระ | ทำมาเพื่อน้องหมาอยู่แล้ว ต้องรับน้องหมา (**ไม่ลงที่รับเฉพาะแมว**) จำกัดขนาดก็ลงได้ แต่ต้องแจ้งให้ชัด: น้ำหนักสูงสุดใส่ `maxDogKg`, รับเฉพาะตัวเล็กใส่ `"small-dogs-only"` ใน `attributes`, กฎอื่นใส่เป็นคำเตือนของหมวด (ขึ้นเตือนในหน้าที่นั้น) |
| ครูฝึก (`trainer`) | ต้องระบุแนวการฝึกให้ชัด: Force-Free หรือ Balance |
| ฟาร์ม (`farm`) | ฟาร์มเพาะพันธุ์จริง (ไม่ใช่ร้านขายสัตว์หรือนายหน้า) ที่ยังเปิดอยู่ ใบเพ็ดดีกรีไม่บังคับ แต่ถ้ามีหลักฐานให้ใส่ `"pedigree"` ใน `attributes` (ขึ้นป้ายทองบนเว็บ) |
| การเดินทางครั้งสุดท้าย (`farewell`) | ไม่มีเกณฑ์พิเศษ (ฌาปนกิจสัตว์เลี้ยง, พิธีส่งน้อง) |

**ตัวอย่างที่ "ไม่ผ่าน" สำหรับคาเฟ่ & ร้านอาหาร**

- รับเฉพาะหมาเล็ก หรือจำกัดน้ำหนัก
- บังคับใส่รถเข็นหรือกระเป๋าในโซนในร้าน (เป็นแค่ทางเลือกได้ แต่บังคับไม่ได้)
- บอกว่าเข้าได้ แต่จริง ๆ ให้อยู่แค่โซนนอก/ลานจอด ขณะที่คนนั่งในห้องแอร์ได้
- บังคับใส่แพมเพิสทุกตัว

ถ้าร้านแค่ "ขอให้ใส่สายจูง" ถือว่าผ่าน

**หลักฐานเรื่องหมาใหญ่:** ควรมีรีวิว รูป หรือคำพูดของร้านที่เห็นว่าหมาพันธุ์ใหญ่ (โกลเด้น, ลาบราดอร์, ฮัสกี้ ฯลฯ) เข้าได้จริง ให้คัดคำพูดนั้นพร้อมเดือน/ปีไว้ใน `notes`

## 4. ฟิลด์ทั้งหมด

ส่งเป็น **array ของ object** (ส่ง object เดียวก็ได้) ใส่เฉพาะฟิลด์ที่มีข้อมูลจริง

| ฟิลด์ | จำเป็น | รูปแบบ / ตัวอย่าง |
|---|---|---|
| `name` | ✅ | ชื่อร้านตามที่ร้านใช้ เช่น `"People & Tail"` |
| `slug` | แนะนำ | ตัวพิมพ์เล็ก a-z 0-9 คั่นด้วย `-` เช่น `"people-and-tail"` ใช้เป็น URL `/place/<slug>` |
| `category` | ✅ | slug ของหมวด (หัวข้อ 5) เช่น `"cafe"` |
| `type` | ถ้าหมวดมี | ประเภทย่อยของหมวดหลัก เช่น `"restaurant"` |
| `trainerStyle` | เฉพาะครูฝึก | `"rplus"` (Force-Free) หรือ `"balance"` |
| `extraCategories` | ไม่จำเป็น | หมวดอื่นที่ให้ที่นี้ขึ้นด้วย เช่น `["park"]` (หัวข้อ 6) |
| `province` | ✅ | ชื่อจังหวัดภาษาไทย เช่น `"กรุงเทพมหานคร"`, `"นนทบุรี"` (ใส่ `"กทม"` ได้) |
| `district` | แนะนำ | เขต/อำเภอภาษาไทย มีหรือไม่มีคำนำหน้าก็ได้ เช่น `"เขตบางนา"`, `"อำเภอปากช่อง"` |
| `coords` | แนะนำ | `"lat, lng"` ทศนิยม เช่น `"13.6667558, 100.6470330"` ใช้กับปุ่ม "ใกล้ฉัน" |
| `mapsUrl` | แนะนำ | ลิงก์ Google Maps ของร้าน (ลิงก์ share `https://maps.app.goo.gl/...` ดีที่สุด) |
| `serviceAreas` | บริการถึงที่ | พื้นที่ที่ให้บริการ ภาษาไทย: `"กรุงเทพมหานคร"` (ทั้งจังหวัด) หรือ `"กรุงเทพมหานคร/เขตลาดกระบัง"` |
| `description` | ✅ | ภาษาไทย 1–2 ประโยค: เป็นที่แบบไหน อยู่ตรงไหน น้องหมาเข้าได้แค่ไหน |
| `hours` | ถ้ามี | เช่น `"ทุกวัน 08:00–20:00"`, `"อ.–ศ. 10:00–17:00 · ส.–อา. 10:00–18:00 · ปิดวันจันทร์"` |
| `price` | ถ้ามี | เช่น `"ราว 101–250 บาท/คน"`, `"เริ่ม 2,500 บาท/คืน"` |
| `phone` | ถ้ามี | เบอร์ของร้าน เช่น `"02-056-9999"` (ใส่ได้เบอร์เดียว ที่เหลือไว้ใน notes) |
| `line` | ถ้ามี | `"@official"` หรือ LINE ID หรือลิงก์ `line.me` |
| `instagram` | ถ้ามี | ลิงก์เต็ม `https://www.instagram.com/xxx/` หรือ `@xxx` |
| `facebook` | ถ้ามี | ลิงก์เต็มของเพจ |
| `website` | ถ้ามี | ลิงก์เว็บไซต์ |
| `attributes` | ถ้ามี | ตัวกรอง/คำเตือนของหมวด (หัวข้อ 5) เช่น `["dog-menu", "parking"]` |
| `maxDogKg` | ที่พัก/บริการสัตว์เลี้ยง | น้ำหนักสูงสุดที่รับ เป็นตัวเลข เช่น `25` (ไม่มีลิมิตไม่ต้องใส่) |
| `maxDogs` | ที่พัก | จำนวนหมาสูงสุดต่อห้อง เช่น `2` |
| `breeds` | เฉพาะฟาร์ม | slug สายพันธุ์ (หัวข้อ 7) เช่น `["golden-retriever"]` |
| `checkedAt` | ไม่จำเป็น | วันที่ตรวจข้อมูล `YYYY-MM-DD` (ไม่ใส่ = วันนี้) |
| `published` | ไม่จำเป็น | ใส่ `false` เพื่อนำเข้าแบบซ่อนไว้ก่อน (ไม่ใส่ = แสดงบนเว็บ) |
| `notes` | ✅ | array ข้อความภาษาไทย: หลักฐานเรื่องหมา (คำพูด + เดือน/ปี), เงื่อนไข, ข้อมูลที่ขัดกัน, สิ่งที่ต้องเช็คต่อ |
| `sources` | ✅ | array ลิงก์ `https://...` ที่ใช้ยืนยัน |

**ร้านที่มีหน้าร้าน** ใส่ `coords` และ/หรือ `mapsUrl` ส่วน **บริการถึงที่** (อาบน้ำตัดขนถึงบ้าน, pet sitter, ครูฝึกสอนถึงบ้าน) ไม่ต้องมี `mapsUrl` ให้ใส่ `serviceAreas` แทน แต่ยังต้องมี `province`/`district` ที่เป็นฐานของบริการ

## 5. หมวด ประเภท และ attributes

`attributes` ใส่ได้เฉพาะค่าที่อยู่ในหมวดของรายการนั้นเท่านั้น ใส่ค่าอื่นจะขึ้นเตือนและถูกตัดทิ้ง
**ตัวกรอง** = สิ่งที่คนใช้ค้นหา (มีจริงถึงใส่) / **คำเตือน** = ข้อจำกัดที่ต้องบอกผู้ใช้

### `cafe` · คาเฟ่ & ร้านอาหาร
- `type`: `cafe` (คาเฟ่), `restaurant` (ร้านอาหาร)
- ตัวกรอง: `dog-menu` (มีเมนูหมา), `parking` (มีที่จอดรถ)

### `vet` · โรงพยาบาลสัตว์ & คลินิก
- `type`: `hospital` (โรงพยาบาล), `clinic` (คลินิก), `specialist` (เฉพาะทาง)
- ตัวกรอง: `open-24h` (เปิด 24 ชม.)
- หลายสาขาให้แยกเป็นคนละรายการ ใส่ชื่อสาขาใน `name`

### `trainer` · ครูฝึกหมา
- ไม่มี `type` แต่ **ต้องมี `trainerStyle`**
  - `rplus` = Force-Free: ไม่ใช้ความเจ็บ ความอึดอัด หรือความกลัว
  - `balance` = Balance: ใช้ทั้งรางวัลและการบังคับ (correction)
- ตัวกรอง: `home-visit` (สอนถึงบ้าน), `day-school` (โรงเรียนไปกลับ), `board-and-train` (ฝากฝึก), `group-class` (คลาสกลุ่ม), `online` (ออนไลน์)
- ระบุไม่ได้ชัดว่าเป็นแนวไหน ให้ใส่ `"published": false` และอธิบายใน notes

### `rehab` · ฟิตเนส & กายภาพ
- ไม่มี `type`
- ตัวกรอง: `fitness` (ฟิตเนส), `physio` (กายภาพบำบัด), `hydro` (ธาราบำบัด), `acupuncture` (ฝังเข็ม)

### `grooming` · อาบน้ำ & ตัดขน
- `type`: `shop` (หน้าร้าน), `mobile` (ถึงบ้าน, ใส่ `serviceAreas`)
- ไม่มีตัวกรอง · คำเตือน: `small-dogs-only`

### `stay` · ที่พักหมาพักได้
- `type`: `hotel` (โรงแรม), `resort` (รีสอร์ท)
- ต้องรับหมา ≥ 15 กก. ถ้ามีลิมิตให้ใส่ `maxDogKg` (ต่ำกว่า 15 จะขึ้นเตือนว่าไม่ผ่านเกณฑ์)
- `maxDogs` = จำนวนหมาสูงสุดต่อห้อง
- คำเตือน (ใส่ทุกข้อที่ที่พักกำหนด):
  - `no-restaurant` ห้ามน้องหมาเข้าร้านอาหาร
  - `no-pool` ห้ามน้องหมาลงสระว่ายน้ำของคน
  - `no-common-areas` ห้ามน้องหมาเข้าล็อบบี้/พื้นที่ส่วนกลาง
  - `no-bed` ห้ามน้องหมาขึ้นเตียง/โซฟา
  - `breed-ban` ห้ามสายพันธุ์หมาดุบางสายพันธุ์
  - `designated-rooms` พักได้เฉพาะห้องที่กำหนด
  - `not-left-alone` ห้ามทิ้งน้องหมาไว้ในห้องลำพัง
  - `leash-required` ต้องใส่สายจูงนอกห้องพัก
  - `diaper-required` ต้องใส่ผ้าอ้อมให้น้อง
  - `vaccine-record` ต้องแสดงสมุดวัคซีน
  - `direct-booking-only` ต้องจองตรงกับที่พัก (จองผ่านแอปไม่ได้)
- ค่าธรรมเนียมหมา (pet fee) ใส่ใน `price` หรือ `notes`

### `boarding` · ฝากเลี้ยง
- `type`: `daycare` (รายวัน), `overnight` (ค้างคืน)
- ไม่มีตัวกรอง · คำเตือน: `small-dogs-only` (`vaccine-record` ใช้ไม่ได้ในหมวดนี้ ให้เขียนใน description/notes แทน)

### `sitter` · Pet sitter & พาเดิน
- `type`: `sitting` (เลี้ยงที่บ้าน), `walking` (พาเดิน)
- ไม่มีตัวกรอง ใส่ `serviceAreas` · คำเตือน: `small-dogs-only`

### `park` · ลานวิ่ง & สระว่ายน้ำหมา
- `type`: `run` (ลานวิ่ง), `pool` (สระว่ายน้ำ)
- ตัวกรอง: `free` (เข้าฟรี), `paid` (เสียค่าเข้า) ใส่ราคาไว้ใน `price`
- จำกัดน้ำหนักใส่ `maxDogKg` เช่น `15`
- คำเตือน: `small-dogs-only` (รับเฉพาะตัวเล็ก ไม่รู้ตัวเลข), `leash-only` (ต้องจูงสายตลอด), `registration-required` (ลงทะเบียนก่อนเข้า), `booking-required` (จองคิวล่วงหน้า), `vaccine-record` (ต้องแสดงสมุดวัคซีน)
- ที่มีทั้งลานและสระ เลือก `type` ที่เด่นกว่า แล้วเขียนอีกอย่างไว้ใน description

### `farewell` · การเดินทางครั้งสุดท้าย
- ไม่มี `type`, ตัวกรอง หรือคำเตือน
- description ใช้ภาษาสุภาพ อ่อนโยน บอกบริการที่มี (เผาเดี่ยว/รวม, เก็บอัฐิ, รับถึงบ้าน)

### `farm` · ฟาร์ม
- ไม่มี `type`
- **ต้องมี `breeds`** (slug ตามหัวข้อ 7)
- ตัวกรอง: `pedigree` (มีใบเพ็ดดีกรี) ใส่ **เฉพาะเมื่อมีหลักฐานชัด** เช่น ฟาร์มประกาศเองว่าออกใบเพ็ดดีกรี หรือมีรูปใบ ให้คัดหลักฐาน + สมาคม (เช่น KAT สมาคมพัฒนาพันธุ์สุนัขแห่งประเทศไทย ทะเบียนขึ้นต้นด้วย KATH หรือ KCT) + เดือน/ปีไว้ใน notes ถ้าไม่แน่ใจ ไม่ต้องใส่ (ฟาร์มยังขึ้นเว็บได้ แค่ไม่มีป้าย)
- ไม่รับร้านขายสัตว์หลายสายพันธุ์ที่ไม่ได้เพาะเอง นายหน้า หรือคนขายรายย่อยครั้งเดียว
- ไม่ต้องใส่ `district` ก็ได้ (ฟาร์มค้นตามสายพันธุ์)

## 6. ขึ้นได้หลายหมวด (`extraCategories`)

ใช้เมื่อที่เดียวกันเป็นได้มากกว่าหนึ่งหมวด เช่น คาเฟ่ที่มีลานวิ่ง หรือ โรงพยาบาลที่มีกายภาพ

- `category` = หมวดหลัก, `extraCategories` = หมวดเพิ่ม (ห้ามใส่ `farm`)
- ตัวกรองของหมวดเพิ่มใส่ใน `attributes` ได้ตามปกติ เช่น `"paid"` ของ `park`
- **ประเภทของหมวดเพิ่ม** ใส่ใน `attributes` แบบ `"<หมวด>:<ประเภท>"` เช่น `"park:run"`, `"vet:clinic"`, `"grooming:shop"`, `"boarding:daycare"`, `"stay:resort"`, `"cafe:restaurant"`

```json
{
  "name": "ตัวอย่างคาเฟ่มีลานวิ่ง",
  "category": "cafe",
  "type": "cafe",
  "extraCategories": ["park"],
  "province": "นนทบุรี",
  "district": "อำเภอปากเกร็ด",
  "attributes": ["parking", "park:run", "paid"]
}
```

## 9. เช็คก่อนส่ง

- [ ] เป็น JSON ที่ถูกต้อง (array ของ object) อยู่ใน code block เดียว ไม่มี comment ใน JSON
- [ ] ทุกรายการผ่านเกณฑ์หมวดในหัวข้อ 3 (ไม่ผ่าน = ไม่ส่ง, ไม่ชัวร์ = `"published": false`)
- [ ] `category`, `type`, `trainerStyle`, `attributes`, `breeds` ใช้ค่าจากคู่มือนี้เท่านั้น
- [ ] `province`/`district` เป็นชื่อไทยที่ถูกต้อง
- [ ] `coords` เป็น `"lat, lng"` (ไม่ใส่ถ้าไม่แน่ใจ)
- [ ] มี `description`, `notes` (มีหลักฐานเรื่องหมา) และ `sources`
- [ ] ไม่มีลิงก์รูปภาพ และไม่มีข้อมูลที่เดาเอง

หลังส่ง ให้สรุปเป็นตารางสั้น ๆ ด้วย: ชื่อ · หมวด/ประเภท · พื้นที่ · ความแน่นของหลักฐาน (ชัด/ปานกลาง/อ่อน) · ข้อควรเช็ค
