# Design Handoff: Sawasdee Dog

อ่านคู่กับ build-spec.md และ design-brief.md. ไฟล์นี้บอกว่างานออกแบบมีอะไร และอะไรยังเป็นการตัดสินใจชั่วคราว

## ในโฟลเดอร์นี้

| ไฟล์ | คืออะไร |
|---|---|
| `tokens.json`, `tokens.css` | สี ฟอนต์ ขนาดตัวอักษร ระยะห่าง มุมโค้ง |
| `icons/category/*.svg` | ไอคอน 11 หมวด ชื่อไฟล์ตรงกับ slug ใน build-spec (เส้น 1.8 บนกริด 24, ใช้ `currentColor`) |
| `icons/ui/*.svg` | ไอคอน UI ทั่วไป |
| `logo/mark-a*.svg` | โลโก้แนว A (ใช้ในทุกหน้าจอตอนนี้) + แบบกลับสีบนพื้นเขียว |
| `logo/mark-b.svg`, `mark-c.svg` | โลโก้แนว B, C (ทีมยังไม่ได้เลือก) |
| `screens/*.html` | ม็อกอัปแต่ละหน้า (M- = มือถือ 390px, D- = เดสก์ท็อป 1280px) ใช้ดูเลย์เอาต์และค่า style ไม่ใช่โค้ดสำหรับ production |

ไฟล์ใน `screens/` เป็นรูปแบบของเครื่องมือออกแบบ (มีแท็ก `<x-dc>`, `<helmet>`) เปิดในเบราว์เซอร์ตรง ๆ อาจไม่เรนเดอร์ ให้อ่านเป็น HTML + inline style เพื่อเอาค่ามาใช้

## ฟอนต์

Google Fonts: Mitr (หัวเรื่อง) และ IBM Plex Sans Thai Looped (เนื้อหา) น้ำหนัก 400/500/600

## แผนที่หน้าจอ -> route

| หน้าจอ | Route |
|---|---|
| M-Home, M-Home-Sponsor, D-Home | `/` (เลย์เอาต์ 2,3,3,3) |
| M-Area | ตัวเลือกย่าน (bottom sheet บนมือถือ) |
| M-Category, M-Category-Empty, D-Category | `/[category]`, `/[category]/[province]/[district]` |
| M-Trainer (แท็บ R+), D-Trainer (แท็บ Balance) | `/trainer...` |
| M-Farm-Breeds, M-Farm-Empty, D-Farm-Breeds | `/farm` |
| M-Farm-List, D-Farm-List | `/farm/[breed]` |
| M-Place, D-Place | `/place/[slug]` |
| M-Criteria, D-Criteria | `/criteria` |
| M-Submit-Login, M-Submit-Form, M-Submit-Done, D-Submit-Form | `/submit` |

## กติกาการออกแบบที่ต้องรักษา

- ปุ่มกดสูงอย่างน้อย 44px
- ปุ่มนำทาง Google Maps ต้องเด่นที่สุดบนหน้ารายละเอียด
- ช่องเด่นที่เป็นสปอนเซอร์ต้องมีป้าย สปอนเซอร์ (พื้นดาวเรือง ตัวอักษรเข้ม) ทุกครั้ง
- แท็บ R+ / Balance ใช้สไตล์เดียวกัน ไม่ใช้สีหรือน้ำหนักต่างกันระหว่างสองฝั่ง
- สีดาวเรือง `#F0A43A` ใช้กับตัวอักษรเข้มเท่านั้น (ตัวอักษรขาวบนดาวเรืองคอนทราสต์ไม่ผ่าน)

## ยังเปิดอยู่ / เป็นข้อมูลตัวอย่าง

- ชื่อร้าน ครูฝึก ฟาร์ม จำนวน และจังหวัดในม็อกอัปเป็นตัวอย่างทั้งหมด ข้อความใน [วงเล็บ] คือตำแหน่งที่รอข้อมูลจริง
- โลโก้: ทีมยังไม่ได้เลือกระหว่าง A / B / C
- ปุ่ม LINE Login ในม็อกอัปเป็นตัวแทน ให้ใช้ปุ่มทางการตาม guideline ของ LINE
- เกณฑ์รับฟาร์มยังไม่สรุป (ตาม build-spec 4.2 ให้ถามก่อน)
- ปุ่มนำทางบนมือถือ: ม็อกอัปวางไว้ใต้ชื่อร้าน ยังไม่ได้ตัดสินว่าจะทำเป็นแถบติดล่างจอด้วยหรือไม่
- ยังไม่มีม็อกอัปเดสก์ท็อปของ: ตัวเลือกย่าน, หน้า login, หน้าส่งแล้ว
